# 部署与运维（给学校管理员）

## Windows 一体机

1. 把 `playtime-windows-amd64.exe` 复制到一个固定目录，例如 `C:\\Playtime\\`，双击运行。
2. 程序会自动选 8730 起的空闲端口，用 Edge 的应用模式全屏打开；没有 Edge 时用系统默认浏览器。
3. 数据在同目录的 `data` 文件夹里，整个文件夹拷走就是完整备份。
4. 想开机自动启动：在该目录的命令行里执行 `playtime-windows-amd64.exe --install-autostart`，取消用 `--uninstall-autostart`。
5. 换机器：把 `data` 文件夹一起拷过去即可。

## Android 一体机

1. 安装 `playtime-android.apk`（minSdk 24），打开即横屏全屏。
2. 数据在应用私有目录，卸载应用会清空；换机器前在老师工作台点「备份」把 zip 拷出来。
3. 系统 WebView 版本低于 100 时应用会提示先在应用商店升级 Android System WebView。

## 手机访问

大屏老师工作台里点「手机版」，出现二维码和地址。手机连同一个 Wi-Fi，扫码即可改通知、名单、奖励。链接 5 分钟内有效，过期重新生成。

如果学校 Wi-Fi 开了设备隔离（手机打不开二维码地址）：让老师手机开热点，一体机连热点，再重新生成二维码。

## 断网

断网不影响玩和看通知，只是工作台里「扩展」页的在线清单刷不出来（内置的口算闯关不受影响）。

## 备份与恢复

工作台「数据」页可以一键备份成 zip（含数据库），恢复时上传同一个 zip。恢复会覆盖当前全部数据，操作前自动留一份 `.bak` 备份在数据目录里。
