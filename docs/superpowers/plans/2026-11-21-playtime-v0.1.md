# Playtime v0.1 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 Playtime v0.1：一台教室一体机上跑起来的本地平台，孩子认领、玩一局口算、得小红花，老师在工作台（大屏或手机）发通知、管名单、批兑换、装扩展，并产出 Windows 与 Android 两个安装包。

**Architecture:** 单个 Go 进程 `playtime` 监听局域网，内嵌前端构建产物，用 SQLite 存全部数据，SSE 推送变更；前端是一套 React SPA，大屏走 `/`、手机走 `/m`；游戏是沙箱 iframe 扩展，通过 MessageChannel 与宿主机通信；Windows 由 exe 自己拉起 Edge 应用模式，Android 由 Kotlin 外壳 + gomobile AAR + WebView 承载。

**Tech Stack:** Go 1.23+（net/http、modernc.org/sqlite、golang.org/x/crypto/bcrypt、mozillazg/go-pinyin）、React 18 + TypeScript + Vite + Tailwind CSS 4 + motion + lucide-react + react-router-dom、Playwright、Gradle(Kotlin) + gomobile、GitHub Actions。

**Spec:** docs/superpowers/specs/2026-11-21-playtime-design.md（实现与本文不符时，先改 spec 再改代码）

## Global Constraints

- 所有面向用户的文案用中文，语气小学化，不用技术词；不得出现 emoji，图标一律 lucide。
- 许可证 AGPL-3.0；仓库不得引入与 AGPL 不兼容的依赖。
- 平台自身零遥测、零云依赖：除「刷新扩展清单 / 安装扩展」外，任何功能必须断网可用。
- 服务端口候选区间 8730–8739，占用则顺延，实际端口与设备令牌写入 `<data>/runtime.json`。
- 数据目录默认 `./data`（exe 同级），可用 `--data` 覆盖；Android 传应用私有目录。
- 大屏按 1920×1080 逻辑分辨率设计，整体等比缩放；可点区域不得小于 48×48 逻辑像素。
- 学生姓名与学号只存本机数据库；不写日志、不导出到任何远端。
- 小红花规则唯一实现：基础 1 朵，正确率 ≥ 80% 得 2 朵，正确率 ≥ 95% 且答对 ≥ 15 题得 3 朵；单人每日 20 朵、全班每日 200 朵；余额 = sum(flower_ledger.delta)。
- 所有写接口要求 `X-Playtime: 1` 自定义头（CSRF），并校验会话。
- Go 依赖版本锁定在 go.mod，前端依赖锁定在 package-lock.json。

## Review Focus

（spec 没写、但一定会有人这么用；每一项都在对应任务的测试里钉住）

1. 重名同音：两个「王小明」拼音首字母都是 wxm —— 候选必须带学号，存在同名时不得自动确认。（T3、T13）
2. 学号形态：前导零（007）、字母混排（A03）、全角数字、大小写混输 —— 匹配与排序要正确，拼音生成失败不能阻断导入。（T3）
3. 半局离开：开一局后关页面、断网、改系统时间，再开一局 —— 未结算的局不能发花，每日上限按流水算而不是按局算。（T6、T9）
4. 双端同时编辑：手机与大屏同时改同一条通知 —— 后写覆盖要有提示，SSE 刷新不能冲掉正在编辑的草稿。（T19、T24）
5. 恶意扩展：提交 correct > total、负数 elapsed、超大 score、非数字字段 —— 服务端必须夹紧或拒绝，不得崩溃或发超量花。（T14、T15）
